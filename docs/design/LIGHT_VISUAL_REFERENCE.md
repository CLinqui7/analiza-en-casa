# Referencia visual light-only

Analiza en Casa utiliza modo claro como única apariencia de producto. El azul/navy del sidebar es un elemento de marca, no un tema oscuro: las superficies de contenido, formularios, tablas, diálogos, estados vacíos y gráficos deben conservar fondo claro, contraste legible y foco visible.

La referencia externa indicada por el cliente se utiliza únicamente para jerarquía de KPI, tarjetas, filtros, tablas y drill-down. No transfiere backend, autenticación, fórmulas, reglas de negocio ni un selector de tema.

Cada validación visual debe cubrir 1440×900, 768×1024 y 390×844; confirmar ausencia de overflow horizontal, foco usable, texto no recortado y estados vacíos honestos.
