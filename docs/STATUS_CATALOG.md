# Catálogo inicial de estados

## Cotización y seguro

| Código | Texto administrativo | Texto para paciente |
|---|---|---|
| DRAFT | Borrador | Estamos preparando su cotización |
| READY_TO_SEND | Lista para enviar | Su cotización está lista |
| SENT_TO_PATIENT | Enviada al paciente | Le enviamos la cotización |
| SENT_TO_INSURER | Enviada al seguro | La solicitud fue enviada a su seguro |
| INSURER_REVIEW | Seguro en revisión | Su seguro está revisando la solicitud |
| INFO_REQUIRED | Información requerida | Estamos completando información solicitada |
| PARTIALLY_APPROVED | Aprobación parcial | Su seguro aprobó una parte |
| APPROVED | Aprobada | Su solicitud fue aprobada |
| REJECTED | Rechazada | La solicitud no fue aprobada |
| PATIENT_PAYMENT | Pago del paciente | Hay un pago pendiente |
| SERVICE_SCHEDULED | Servicio programado | El servicio puede programarse |
| CLOSED | Cerrada | El proceso fue completado |
| CANCELLED | Cancelada | El proceso fue cancelado |

## Documentos clínicos

- DRAFT.
