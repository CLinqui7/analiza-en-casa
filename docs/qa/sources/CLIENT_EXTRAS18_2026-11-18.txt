Ajustes extra, adicionales al flujo nuevo
Ajustes
Clínico → Órdenes médicas → Acciones médicas
Cambiar el nombre de la tarjeta "Antecedentes clínicos" por "Antecedentes personales".
Clínico → Órdenes médicas (Acciones médicas y Acciones de enfermería)
El campo Hospitalización se mantiene como selector, pero debe permitir buscar escribiendo. Ejemplo: si el paciente tiene muchas y se busca la 444, al escribir "44" deben aparecer las coincidencias para seleccionar.
Clínico → Órdenes médicas → Acciones de enfermería → Planes de cuidado
Hoy, al seleccionar uno o varios tipos de plan (Dieta, Cuidado de enfermería), aparece un solo campo "Descripción" para todos.
Debe aparecer un campo de descripción por cada tipo seleccionado:
Si se selecciona Dieta: campo "Descripción de dieta".
Si se selecciona Cuidado de enfermería: campo "Descripción de cuidados de enfermería".
Si se seleccionan ambos, aparecen los dos campos, cada uno por separado.
Clínico → Expediente clínico
Así como se pueden imprimir las secciones (una, varias o el expediente completo), se deben poder descargar en PDF con las mismas opciones. Hoy esa opción no existe.
Clínico → Órdenes médicas → Acciones de enfermería → Tarjeta de medicamentos
Se mantiene que la tarjeta carga por default todos los medicamentos de la cotización.
Agregar que también cargue los productos de la cotización cuyo nombre contenga "Solución" o "Soluciones" (no existe una categoría Soluciones; se identifican por el nombre del producto).
