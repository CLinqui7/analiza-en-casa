# Brechas abiertas antes de producción real

Estas brechas no son funciones omitidas del prototipo. Son datos, reglas o documentos que el video no permite definir con certeza.

| Brecha | Estado del proyecto | Qué debe entregar o aprobar el cliente |
|---|---|---|
| Cotización oficial impresa | Plantilla provisional funcional | PDF o muestra oficial |
| Reporte de salud oficial | Plantilla provisional funcional | Secciones, firmas y formato |
| Orden médica oficial | Plantilla provisional funcional | Formato y reglas de firma |
| Tarjeta de medicamentos | Flujo y plantilla provisional | Campos y controles oficiales |
| Plan de cuidados | Flujo y plantilla provisional | Formato y responsables |
| Estado de cuenta médico | Flujo y plantilla provisional | Fórmula, retenciones y fechas |
| Precios y costos | Catálogos sintéticos e importación preparada | Excel oficial |
| Cobertura de seguros | Flujo manual configurable | Reglas por plan o integración |
| Descuentos | Motor por categoría | Perfiles y autorizadores |
| IVA e impuestos | Campo configurable | Regla fiscal validada |
| Mensajería real | Adaptador y cola preparados | Proveedor, plantillas y consentimiento |
| Firma clínica | Estados y bloqueo implementados | Política legal y tecnológica |
| Inventario inicial | Estructura, lotes y cierres | Existencias, bodegas y unidades |
| Migración histórica | Importadores previstos | Archivos fuente y reglas de limpieza |
| Volumen y concurrencia | Arquitectura preparada | Estimación y prueba de carga |
