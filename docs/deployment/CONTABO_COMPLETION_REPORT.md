La primera corrida local de navegador heredó el modo MongoDB de `.env.local` y los usuarios demo no pudieron entrar; se detuvo y se repitió con modo sintético explícito. La corrida completa de desarrollo mostró un clic lateral intermitente, mientras el mismo caso pasó repetido y la suite de producción terminó limpia. No se cambió el comportamiento de la aplicación para ocultar la incidencia.

La copia diaria de PostgreSQL usa `pg_dump` consistente y archivos privados; el script detiene brevemente la web para mantener coherencia entre ambas fuentes. Un respaldo continuo sin esa pausa requiere un mecanismo de snapshot coordinado y una prueba de recuperación adicional. El crecimiento del repositorio se observa por disco y salud, pero la política de retención no se inventó. La tarea Windows depende de esta PC encendida y de una sesión interactiva; el resultado del programador debe supervisarse hasta disponer de un destino independiente con alerta.

El PR #19 permanece en borrador sobre `codex/contabo-clean-migration`, sin merge a `main`. El rollback web conserva la imagen previa; las migraciones aditivas no se revierten automáticamente. El cambio de dominio y la promoción de datos clínicos a la base operativa quedan excluidos de esta ejecución.
