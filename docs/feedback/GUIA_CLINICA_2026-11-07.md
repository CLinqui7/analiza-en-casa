# Uso de los cambios clínicos del 7 de noviembre

## Configurar el consumo una vez por medicamento

1. Abra **Administración → Diagnósticos y escalas → Consumo de medicamentos**.
2. Agregue una configuración y seleccione el medicamento de inventario, la bodega de origen y las unidades de inventario que deben salir por aplicación.
3. Guarde. Para cambiar esos datos después, edite la misma configuración.

Estos valores los define el equipo. Las unidades de inventario no se deducen de la dosis ni de la cantidad cotizada. La cotización debe tener vinculado el artículo de inventario correspondiente. Las configuraciones nuevas se aplican a consumos nuevos; el historial conserva el origen y las unidades que se utilizaron.

Las tarjetas históricas que ya tenían una asignación propia de inventario la conservan. Para utilizar la configuración común en ese caso, cree una nueva tarjeta con las indicaciones del equipo.

## Tarjeta y administración

En **Clínico → Órdenes médicas → Acciones de enfermería → Tarjeta de medicamentos**, seleccione paciente e ingreso. Aparecen los medicamentos cotizados. Para cada uno, capture las horas indicadas, use **Agregar hora** si necesita más y escriba la dilución cuando corresponda. **Crónicos** permanece al final.

Al abrir **Administración de medicamentos**, aparecen esas horas. Seleccione la fecha y registre únicamente las aplicaciones que correspondan; si marca que no se aplicó, capture el motivo. Complete el detalle de administración y guarde. Las aplicaciones ya registradas para esa fecha se muestran identificadas.

El sistema registra el consumo con la configuración guardada. Si falta el vínculo de inventario, origen, unidades o existencias utilizables, muestra el motivo y no guarda una administración parcial. **Configurar consumo** abre la configuración en otra pestaña para conservar el formulario.

Para corregir un registro, use **Editar** e indique el motivo. Se conserva la versión anterior. Al corregir una aplicación registrada como aplicada a no aplicada, se compensa únicamente su consumo; los otros horarios permanecen intactos. Las correcciones de tarjeta conservan horarios y dilución al revisar la misma línea de cotización, si sigue siendo el mismo medicamento.

## Imprimir

En **Clínico → Expediente clínico → Abrir expediente**, use **Imprimir sección** para seleccionar uno o varios grupos: Resumen, Acciones médicas, Acciones de enfermería y Visitas. En esa ventana, **Seleccionar expediente completo** marca todos los grupos. La pestaña **Expediente completo** también ofrece **Imprimir expediente completo**. Revise paciente e ingreso antes de imprimir.

La selección incluye el grupo completo, aunque en pantalla estuviera filtrado un tipo de registro. También se conserva la impresión individual de cada documento.
