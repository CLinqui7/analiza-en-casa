# Video audit instructions

This directory contains source evidence and is immutable.

- Do not edit, rename, optimize or delete any file under `references/video-audit/`.
- Write all observations and receipts under `video-audit-reviews/`.
- Review chapter evidence in batches using each chapter's `CODEX_IMAGE_BATCHES.md`.
- Then inspect every individual file referenced by `event_manifest.csv`.
- Use the exact chapter clip only to resolve timing, interaction sequence or audio ambiguity.
- A contact sheet is an index, not a substitute for the individual frame review.
- Run `npm run audit:verify` before claiming a chapter is complete.
