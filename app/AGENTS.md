# Frontend/application rules

- UI hiding is not authorization. Server and database permissions remain authoritative.
- Preserve clear language, visible states, keyboard access, focus management and responsive layouts.
- Every action needs loading, success, empty and error behavior.
- Prevent accidental double submission.
- Never display internal enum codes to patients.
- Patient-facing text must explain the current state and the next action.
- Do not expose clinical content in public or notification views.
