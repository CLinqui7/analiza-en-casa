# Review outputs

Evidence is immutable under `references/video-audit/`. All Codex observations belong here.

Each chapter directory contains:

- `event_review_notes.csv`: one required observation per event.
- `chapter_feature_inventory.json` and `.md`.
- `chapter_open_questions.md`.
- `chapter_review_receipt.json`.

Run:

```bash
npm run audit:status
npm run audit:verify
```
